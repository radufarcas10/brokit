CI & agents

Made for pipelines and for agents.

Every run ends in an exit code your CI understands and, with --json, a result a script or an AI agent can read: each step, its value, the console, every error.

  • Plain answers: 0 when everything worked, 1 when the page failed, 2 when brokit was run wrong.
  • Same pixels everywhere: --gpu software draws identically on a laptop and a CI runner.
  • Safe to hand to an agent: local pages only, a sandboxed throwaway browser, files written only where you say.
