Steps

Steps anyone can read. Or write.

A check is a short JSON list: click here, type this, press that, look. A teammate can review it, and an AI agent can write it without learning an API.

  • Point anywhere: coordinates, a CSS selector, a spot inside a canvas, or a JS expression.
  • No guessing at timing: after each input the page gets a frame, and expect waits for the page to catch up.
  • Read the page back: eval or expect any expression; its value lands in the report.
