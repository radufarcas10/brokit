Light to install

One npm package, a 51 kB download, with no npm dependencies to audit: it's built on Node's own modules. It drives the Chrome you already have; brokit install-chrome fetches one if you don't.

Input a person would give

Mouse, wheel, keys, touch and input methods go through Chrome's own input pipeline. Your page can't tell them from a person's, so what passes here works there.

Safe by default

Pages on your computer only, unless you name a host. A throwaway profile, Chrome's sandbox on, and every file it reads treated as untrusted.
