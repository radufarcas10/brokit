Install

Start in a minute.

brokit comes from npm. It needs Node.js 22.4 or newer, and Chrome, Chromium or Edge, which it finds on its own (or brokit install-chrome downloads one).

  1. Add it to your project

    {{copy:npm install --save-dev brokit}}

  2. Check your setup

    {{copy:npx brokit doctor}}

  3. Open a page

    {{copy:npx brokit run index.html --out shot.png}}

  4. Give it steps

    {{copy:npx brokit run index.html --steps steps.json}}

  5. Check everything

    {{copy:npx brokit check}}

Not on npm yet. Until it is, add it from GitHub instead, and the rest works the same: npm install --save-dev github:radufarcas10/brokit. To run it from a clone, see Before brokit is on npm.
