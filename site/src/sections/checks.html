Checks

Run them all. Remember how it looked.

brokit check runs every *.check.json in your project in one Chrome. Screenshots marked as baselines are compared with the approved ones, kept next to your checks and reviewed in git like code.

  • One browser for the suite: ten checks took 3.1 s of CPU, against 8.2 s with a browser for each.
  • Mistakes fail fast: every check is read before Chrome starts, so a typo costs milliseconds.
  • Changes on purpose: --update approves them. In CI, a missing baseline fails instead of quietly passing.
