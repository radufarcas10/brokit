At a glance

What brokit is, and who it's for.

What it is
A command-line tool and a Node.js library. It drives a headless Chrome: it opens your pages, clicks, types and taps, reads what they show, and compares screenshots with ones you approved.
Who it's for
Web developers checking their own pages, teams that want those checks to run in CI, and AI coding agents that need to see and use what they build.
Where it runs
On your computer (Linux; macOS and Windows not tested yet), in CI (GitHub Actions, GitLab CI, Docker), and anywhere an agent can run a command.
What it needs
Node.js 22.4 or newer, and Chrome, Chromium or Edge, which it finds on its own. No Chrome? brokit install-chrome gets one. Installing brokit adds one package, a 51 kB download (about 160 kB on disk): it has no npm dependencies.
Where to get it
From npm: npm install --save-dev brokit, or npx brokit without installing. Free and open source, under MIT or Apache-2.0.
How to start
npx brokit doctor checks your setup, npx brokit run index.html opens a page; the docs cover steps, checks, baselines and CI.
